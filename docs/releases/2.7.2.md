# FNLLA Core 2.7.2

Core 2.7.2 updates starter repository hygiene and maintained guidance. Runtime
interfaces and persisted data formats remain unchanged from 2.7.1. Availability
requires the immutable package and successful CI for its exact source commit.

## Changes

- Generated starters ignore nested environment files, credentials, private keys,
  database files, uploads, local editor state and test/build output. Explicit
  environment examples remain available for source control.
- Clarify repository ownership and reproducible generated/build outputs.
- Declare the unchanged Core contracts for the FNLLA 4 application adapter.

## Upgrade and rollback

Install the reviewed immutable package through Composer; do not edit vendor.
There are no database, queue or runtime migrations from 2.7.1. A dependency
update does not rewrite application-owned ignore rules: review starter rule
changes explicitly and retain existing application exceptions. Ignore rules do
not untrack files or remove secrets from history. Use the normal journalled
application update and recovery flow; never replace a previous package or tag.
